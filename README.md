# المستشار إسلام الغرياني

موقع قانوني عربي احترافي مبني بـ **Next.js + TypeScript + Tailwind + Framer Motion + Three.js/R3F + GSAP**.

## تشغيل المشروع

```bash
npm install
npm run dev
```

## بناء الإنتاج

```bash
npm run lint
npm run build
npm run start
```

## ملاحظات الإعداد

- التخطيط عربي RTL بشكل كامل.
- يمكن تخصيص رابط الخريطة عبر المتغير:

```bash
NEXT_PUBLIC_GOOGLE_MAPS_EMBED="https://www.google.com/maps?q=Cairo%20Egypt&output=embed"
```
